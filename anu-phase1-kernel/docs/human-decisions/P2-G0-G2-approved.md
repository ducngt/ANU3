# Phase 2 Human Decision Record — G0/G1/G2

## G0/G1 — APPROVED

Use ARU-01 synthetic institutional data for the Phase 2 pilot. No real learner PII is used in this tranche.

## G2 — APPROVED

Guardrails:

1. Source Authority is not Storage Location.
2. University Memory is not a source of truth; it indexes traceable institutional memory back to authoritative records.
3. AI inference/prediction/recommendation does not self-promote into Fact, Evidence or Decision.
4. Official Fact/Evidence/Decision-like state requires registered source authority plus provenance and validation.
5. Missing source authority fails closed.
6. Consequential state supports effective-time + recorded-time replay.
7. History is append/supersede; no destructive rewrite of provenance.
8. Connecting real SIS/LMS/HR data requires a separate Human G2 on privacy, retention, access scope and source authority.
